The Perfect Form

Every mobile web form feature I could think of, marked up with best practices, to see how well iOS Safari fills it from a contact card, a password manager, and saved cards. Nothing leaves this device: there is no server, and submitting only shows a local report of what was filled (passwords and card numbers are masked). The grey text under each field is the markup that drives its behavior.

Contact & address

Tap a field and pick “AutoFill Contact” above the keyboard. One tap should fill everything here.

Create account

Safari should suggest your email, offer a strong password that follows the rules below, and offer to save the login when you submit.

At least 12 characters.

Sign in

The keyboard should offer the saved login for this site (after Face ID), or the key icon to pick one.

Passkey

Creates a real passkey for this site in your password manager, then signs in with it. Nothing verifies it, so it is only a test of the system sheets. Delete it afterwards in Passwords.


  


  
  

    
One-time code

    
When a text message with a code arrives while this field is focused, iOS offers it above the keyboard. Text yourself “Your code is 123456” to try it.
